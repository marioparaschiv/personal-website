## Solution

Enmity is an open-source modification for Discord's iOS app that enables plug-ins and themes, giving users the ability to extend and personalize their mobile Discord experience. It served as the foundation that later evolved into Unbound.

## Key Features

- **Plugin Support** — Install community-built plug-ins that add new capabilities to Discord's iOS app
- **Custom Themes** — Apply visual themes that transform the app's appearance to your liking
- **Native Integration** — Injected at the native level for seamless, stable operation alongside the stock app
- **Developer-Friendly** — Provided a straightforward API for plug-in and theme developers to build on
