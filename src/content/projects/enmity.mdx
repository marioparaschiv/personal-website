Enmity brings plugins and themes to Discord on iOS, which Apple's ecosystem makes deliberately difficult. It works by injecting at the native level, which keeps things stable, and ships with an API that lets the community write their own plugins and themes.

Its successor is Unbound, which takes the same idea and expands it to Android.
