Discord doesn't let you customize its mobile app. No plugins, no themes, nothing. Unbound is an open-source mod that changes that, running on iOS and Android from a single codebase.

Users can install community plugins, swap themes, and change fonts and icons. The goal is write-once, run-everywhere, so everything works the same on both platforms.
